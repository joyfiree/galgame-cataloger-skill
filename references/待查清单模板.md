## 反复出现的困难案例（值得记进规则）

这些不是「查不到」，而是「查错了」，容易被误认为成功：

| 现象 | 真实原因 | 规则 |
|---|---|---|
| 候选是「はじめに」「ご挨拶」 | readme 目录项，不是标题 | 排除章节名，真名在目录项之前 |
| 标题带「绅士回廊云翻」 | 转录组水印 | 剥离水印词 |
| 标题带「（大概）」 | 打包者自己不确定 | 降级 D，需外部确认 |
| 候选是 `chardetect` | Ren'Py 自带工具 | 排除 `lib/` 路径 |
| 纯数字目录名 `2109284216` | 製品番号 | 查数据库 |
| `_32`/`_64` 成对 | 同游戏位版本 | 归并，不当两部作品 |
